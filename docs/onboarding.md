# 新插件接入流程

本市场只收录 Tealun 自己的插件。每个插件在自己的仓库里开发和发布，本仓库只放清单。清单、README 和本文件由市场维护者统一维护。

## 一、接入前提（缺一项就不加条目）

1. **仓库公开**：市场从 GitHub 匿名读取插件。
2. **发布分支已存在**：插件仓库推过一次 `v<版本>` tag，CI 已把打包好的插件写进发布分支（默认 `plugin`）。发布分支只由 CI 写入。
3. **打包后的插件通过校验**：对发布分支的内容运行 `claude plugin validate`，没有错误。
4. **插件仓库里没有 `marketplace.json`**：市场清单只放在本仓库。

`python3 scripts/check_marketplace.py --remote` 会检查第 1、2 条，CI 每次推送都会运行。

## 二、一个仓库里有多个插件

每个插件各用一条发布分支，命名为 `plugin/<插件名>`，由 CI 在推送 `<插件名>-v<版本>` tag 时写入。清单条目的 `ref` 填对应的分支。

## 三、接入步骤

1. 插件仓库完成发布流水线，推送第一个 tag，确认发布分支已经存在。
2. 开 PR（分支名 `add/<插件名>`），只改 `.claude-plugin/marketplace.json`，加一条。
3. 维护者核对接入前提、运行检查，在隔离环境里试装一次。通过后合并，同时更新 README 的插件表。
